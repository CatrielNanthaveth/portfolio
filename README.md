# **Catriel Nanthaveth - Personal Portfolio**

A creative and interactive portfolio built with React and Tailwind CSS, inspired by the aesthetics of modern music platforms.

**[Live Demo](https://url.com)**

-----

## **About This Project**

This portfolio was designed not just as a resume, but as an interactive experience. The core concept is to present my professional journey and projects through the metaphor of a music album, with sections like a "Tracklist" for navigation and a "Discography" for my featured work. The goal was to create a memorable, clean, and modern showcase of my skills as a Full Stack Developer.

## **Key Features**

  * **Interactive Playlist Navigation:** The main menu is designed as a "Tracklist," allowing users to jump to different sections of the portfolio.
  * **Dynamic Project Gallery:** Projects are displayed in a grid of cards. Clicking a card opens a modal window with detailed information, including links to the live site and GitHub repository.
  * **Themed Components:** All components, from the "Player Cards" to the contact buttons, follow a cohesive, dark-mode, Spotify-inspired aesthetic.
  * **Responsive Design:** The entire layout is fully responsive, ensuring a great user experience on both desktop and mobile devices.

## **Getting Started**

To run this project locally, follow these steps:

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/your-username/your-repo-name.git
    ```
2.  **Navigate to the project directory:**
    ```bash
    cd your-repo-name
    ```
3.  **Install the dependencies:**
    ```bash
    npm install
    ```
4.  **Run the development server:**
    ```bash
    npm run dev
    ```
    The application will be available at `http://localhost:5173` (or another port if 5173 is in use).
